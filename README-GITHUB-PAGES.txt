GitHub Pages:
1. Put ALL files in the same repository folder (normally the repository root).
2. Settings -> Pages -> Deploy from branch.
3. Select your branch and /(root).
4. Open the exact published Pages URL.
5. If Chrome still shows an old version, hard-refresh or clear the site's cached data once.
6. Search terms use the selected search provider; URLs such as example.com open directly.

Important:
The URL must be entered as a normal address, without square brackets.
Example:
https://ha0812051-sys.github.io/Hassanweb.com/
