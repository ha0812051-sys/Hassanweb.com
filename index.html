ABOUT HASSAN

About Hassan Browser

Hassan Browser 2.0 is a lightweight browser-style search interface focused on a clean search experience, quick website access and local history.

YOUR PRIVACY

Privacy

Hassan Browser 2.0 does not provide its own server-side search index. Search requests are sent to the search provider you select.

Search history is stored in your browser's local storage. Clearing browser storage or using the Clear All button removes it from this device.
